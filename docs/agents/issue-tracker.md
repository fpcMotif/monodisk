# Issue tracker: GitHub

Issues and specifications live in this repository's GitHub Issues.
Use `gh` and infer the repository from `git remote -v`.
Read tickets with `gh issue view NUMBER --comments`.
Publish tickets with `gh issue create --title TITLE --body-file FILE`.
Use `gh issue edit` for labels and `gh issue close` after verification.
Publishing a ticket requires user authorization or an explicitly invoked publishing skill.

PRs as a request surface: no.
